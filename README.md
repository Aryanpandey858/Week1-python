# Week 1 - Python

Assignments and mini project for Week 1 (loops, conditionals, modular programming).

## Programs

| File | Description |
|------|-------------|
| `temperature_converter.py` | Converts Celsius <-> Fahrenheit using functions |
| `grade_calculator.py` | Takes marks as input, calculates average and assigns a grade |
| `even_odd_prime.py` | Checks whether a number is even/odd and prime |
| `atm_simulator.py` | Mini project: PIN-based ATM with balance, deposit, withdraw |

## How to run

```
python temperature_converter.py
python grade_calculator.py
python even_odd_prime.py
python atm_simulator.py
```

ATM demo PIN: `1234`
